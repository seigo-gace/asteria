# Language Capability

AsteriaAI accepts syntactically valid BCP47 target languages and optional source languages, but acceptance of a language tag is not a quality guarantee.

Current capability status returned by the API is `NOT_VERIFIED` for all language pairs until a human-reviewed regression corpus and live full-service benchmark establish pair-specific evidence.

Required future evidence classes include CJK, RTL, European languages, low-resource languages, emoji, mixed scripts, Markdown/table/code/placeholder preservation, negation, conditional language, quantities, money, dates, and adversarial embedded instructions.
